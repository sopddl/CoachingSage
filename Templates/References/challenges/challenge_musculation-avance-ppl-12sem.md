## Issues importantes (à corriger avant bundle idéal)

- **[W10 J3]** Back squat barre : la note dit "*Progression de charge de 2,5 kg sur les composés où la fourchette haute a été atteinte en W9*" mais ne clarifie pas si cette progression doit s'appliquer systématiquement ou seulement si W9 a délivré RPE 9 réussi. Ajouter : "*si 6 reps atteintes à RPE 8 minimum en W9*" pour éviter une surcharge prématurée.

- **[W5-W8 : Bloc 2 rest-pause]** Rest-pause annoncée dans progression_logic comme "*15 sec isolations uniquement*" mais W5 J1 précise "*dernière série uniquement*" tandis que W6-W7 appliquent rest-pause sur 3-4 séries d'isolations (élévations, curls). Harmoniser : appliquer rest-pause systématiquement sur la **dernière série seulement** des isolations du Bloc 2, pas sur toutes les séries, pour respecter le dosage annoncé et éviter surcharge métabolique cumulative.

- **[W9-W11 : drop sets et pause reps combinés]** Progress_logic annonce "*drop sets simple puis double à partir de W9*" et "*pause reps en W9-W11*" mais combine dans les mêmes séances (ex: W9 J1 = élévations latérales DROP SET + triceps pushdown DROP SET + dips + bench PAUSE REPS + incliné PAUSE REPS). Ceci crée un volume métabolique très agressif en fin de séance. Clarifier dans les notes : "*les drop sets s'appliquent aux isolations (élévations, curls, pushdown), les pause reps aux composés de base (bench, incliné, OHP)*" pour une application plus stratégique du stress.

- **[W12 J3 : Leg extension]** Deload dit RPE 6 mais note "*charge très légère*" — leg extension en deload risque toujours une douleur rotulienne même léger chez certain(e)s. Recommander une alternative : "*Sissy squat partiel 3x15 ou leg press machine très légère si sensibilité genou en extension*".

## Issues mineures (nice-to-have)

- **[W1-W4 : progression_logic vs reality]** Progression_logic prétend "*5 principes*" mais le 5e (pullover câble intro W2) est décrit comme complément isolé, non comme principe de progression. C'est un détail mineur mais entache la clarté de structure. Soit renommer en "*4 principes + 1 exercice clé*", soit intégrer l'évolution des patterns (quad dominant → ischio dominant par séance) comme le 5e principe.

- **[Safety_notes : FC de repos]** "*FC de repos +10 bpm au réveil*" est cité comme indicateur, mais aucune séance d'anchor ou test spécifique n'est proposé pour le mesurer systématiquement (pas de protocole FC repos inscrit en W1 J1). Ajouter : "*mesurer FC repos à jeun 3x/semaine (lundi/mercredi/vendredi) et consigner pour détecter la dérive*".

- **[W3 squats : volume]** Back squat passe de 4 sets (W1-W2) à **5 sets** en W3, RDL pareil. C'est une augmentation non progressive (pas de +1 set en W2). Devrait être : W1 = 4 sets, W2 = 4 sets, W3 = 5 sets, ou W1 = 3 sets, W2 = 4 sets, W3 = 5 sets. Minor mais visible.

- **[W12 : checklist d'autoévaluation]** Excellent pédagogiquement mais le "day 5" est conçu comme évaluation+séance = charge cognitive/physique mélangée. Recommander : exécuter Pull B normal, puis le jour 6 ou le lendemain faire une séance très légère isolée d'évaluation (bodyweight tests, charges W1 comparatives) sans fatigue accumulée.

- **[Core en fin de séance : application stricte]** Safety_notes est ferme : "*core TOUJOURS en fin de séance*". Vérification : **toutes les séances le respectent** ✓ (planche J1, dead bug J2, etc.). Bon.

## Manques notables

- **Protocole "séance manquée"** : safety_notes le couvre, mais pas d'indication dans les semaines sur comment recaler le split si une séance est manquée (ex: si Push A J1 est manqué, la faire J2 matin ou l'intégrer à la fin de semaine ?). Ajouter une note générique : "*En cas de séance manquée, reprogrammer au plus tôt dans les 48h en respectant la fréquence 2x/groupe/semaine*".

- **Substitutions d'exercices** : template est très prescriptif. Aucune note sur les alternatives si un équipement manque ponctuellement (ex: pas de banc incliné → utilise DB press à 30° ou chest fly machine). Ajouter en W1 J1 : "*substitutions tolérées pour les isolations (élévations, curls) ; les 6 patterns (squat, hinge, push H, push V, pull H, pull V) doivent être maintenus*".

- **Signaux d'arrêt claire pour chaque pattern** : safety_notes couvre les drapeaux rouges (douleur épaule, lombaire, genou) mais pas de seuil clair pour "*quand réduire la charge de 20% vs arrêter*" pour chaque groupe. Ex: "si douleur coude French press > 3/10 sur 2 séances, remplacer l'exercice" — c'est implicite, pas explicite.

- **Progression du core** : core toujours en fin, mais la progression est aléatoire (planche 40 sec W1 → 60 sec W11, pas de pattern linéaire). Clarifier : "*core doit progresser en durée (+5 sec/semaine) ou reps (+2-3 reps/semaine) en parallèle des composés*".

- **Enregistrement logbook** : safety_notes le demande, mais **aucune structuration proposée**. Ajouter une template simple en fin du document : "*Template logbook : [Date] [Exercice] [Charge] [Reps par série] [RPE finale] [Notes douleur/technique]*".
