# Adaptability : running-expert-marathon-16sem + p1-reduce-frequency

## Rigidity score
**4/10**

Le template est **modérément rigide** pour une réduction à 2 séances/sem. La structure progresse par blocs (Bloc 1-4) avec des principes strictement définis (tempo + VO2max TOUTES LES SEMAINES, long run progressif, cutbacks réguliers). Une réduction à 2 séances force des arbitrages violents entre ces principes, créant des contradictions.

---

## Patch approach

Priorité absolue : **conserver 1 séance qualité (tempo OU VO2max alternant semaine à semaine) + 1 long run**, sacrifier entièrement la séance force et l'un des deux types d'intervalle. Cette stratégie respecte partiellement la progression_logic (blocs + cutbacks) mais viole le principe 3 (« TOUTES LES SEMAINES sans exception »). Les 4 premières semaines posent moins de problème (W1-W4 : tempo/VO2max sont plus courts) ; l'affûtage (W13-W15) devient gérable; mais W5-W12 demandent des choix irréversibles.

---

## Concrete modifications

**Stratégie générale : alternance tempo/VO2max semaine à semaine**

- **W1** : Conserver J1 (run facile 40 min) + J3 (tempo 20 min) → 1 séance qualité. Supprimer entièrement J2 (force), J5 (VO2max). Long run J7 18 km inchangé. **Total : ~35 km** (vs 55 km prévus = -36%).

- **W2** : Conserver J1 (run facile 42 min) + J5 (intervalles 6x600m) → 1 séance qualité VO2max. Supprimer J2 (force), J3 (tempo). Long run J7 21 km inchangé. **Total : ~40 km**.

- **W3** : J1 facile + J3 (tempo 2x16 min fractionné) → tempo revient. J5 VO2max SUPPRIMÉ cette semaine. J2 force supprimé. Long run 24 km inchangé. **Total : ~42 km**.

- **W4 (cutback)** : Réduire à J1 facile (40 min) + J3 (tempo 20 min court). Supprimer J2, J5. Long run 18 km. **Total : ~33 km** (cutback prévu ~56 km → vous atteignez ~33 km = -41% vs W3 = acceptable pour un cutback).

- **W5-W12 (Blocs 2-3)** : 
  - **Semaines impaires (W5, W7, W9, W11)** : J1 facile + **J3 tempo** (à allure seuil identique, réduit de ~25% en durée). Long run avec portion AM. Supprimer J2 force + J5 VO2max.
  - **Semaines paires (W6, W8, W10, W12)** : J1 facile + **J5 intervalles VO2max** (réduit de ~25% : ex W6 = 4x1000m au lieu de 6x1000m). Long run avec portion AM. Supprimer J2 force + J3 tempo.

  Exemples concrets :
  - **W5** (tempo) : J1 facile 45 min + J3 tempo 30 min (vs 30 min continu prévus = acceptable, c'est le pic de W5) + J7 long run 26 km = **~50 km** (vs 63 km prévus = -21%).
  - **W6** (VO2max) : J1 facile 48 min + J5 intervalles 4x1000m (vs 6x1000m prévus) + J7 long run 27 km = **~50 km**.
  - **W7** (tempo) : J1 facile 50 min + J3 tempo 35 min continu (le pic W7 du plan = inchangé sur la qualité) + J7 long run 29 km = **~55 km** (vs 68 km = -19%).
  - **W8 (cutback)** : J1 facile 40 min + J5 intervalles réduits 4x800m (vs 5x1000m prévus) + J7 long run 22 km = **~40 km** (vs 56 km prévus cutback = acceptable).
  - **W10** (VO2max) : J1 facile 52 min + J5 intervalles 4x1000m (vs 6x1000m prévus) + J7 long run 32 km = **~55 km** (vs 69 km).
  - **W11** (tempo) : J1 facile 45 min + J3 tempo 40 min (le pic de la saison = maintenu) + J7 long run 35 km = **~65 km** (vs 75 km prévus = -13%, acceptable car W11 est le volume pic et le long run 35 km est non-négociable).
  - **W12 (cutback)** : J1 facile 40 min + J3 tempo 2x20 min (réduit) + J7 long run 23 km = **~40 km** (vs 60 km).

- **W13-W15 (affûtage)** : Structure devient plus viable à 2 séances.
  - **W13** : J1 facile 42 min + J3 tempo 25 min (maintien intensité, réduction volume) + J7 long run 28 km = **~48 km** (vs 51 km prévus = -6%, acceptable).
  - **W14** : J1 facile 35 min + J5 run AM 30 min + J7 long run 20 km = **~32 km** (vs 38 km).
  - **W15** : J1 facile 25 min + J3 run AM 20 min + 6 strides (pas de long run, cadre déjà minimaliste) = **~20 km** (vs 25 km).

- **W16 (race week)** : J1 shakeout 15 min + J3 run AM 15 min + J7 marathon 42,2 km. Inchangé logiquement.

## Rigidity issues

1. **Violation du Principe 3 (« TOUTES LES SEMAINES sans exception »)**
   - Le template stipule : « SÉANCES TEMPO ET VO2MAX TOUTES LES SEMAINES SANS EXCEPTION (règle 3.1 running expert) ».
   - Votre adaptation : alternance tempo/VO2max = chaque type d'intervalle est **supprimé une semaine sur deux en W5-W12**.
   - **Risque** : perte partielle du stimulus seuil ou VO2max sur 4 semaines cumulées (W6, W8, W10, W12 sans VO2max; W5, W7, W9, W11 sans tempo). Cela affecte directement la progression_logic « Développement seuil lactique + VO2max » du Bloc 2 (W5-W8).

2. **Suppression totale du renforcement (W1-W12, partiellement W13-W15)**
   - La progression_logic stipule : « RENFORCEMENT PRÉVENTIF SPÉCIFIQUE EXPERT » avec progression de 5-6 reps Nordic curl en W1 à 8 reps+4 séries en W10.
   - Votre adaptation : J2 (jour force) est entièrement supprimé → Nordic curls, calf raises excentriques, single-leg squats disparaissent.
   - **Risque critique** : la safety_notes identifie la tendinopathie proximale ischio-jambière (ischios) et tendinopathie d'Achille comme risques n°1 chez le marathonien pratiquant intervalles haute vitesse. Sans Nordic curls (étude Mjølsnes 2004 = or standard prévention) et calf raises excentriques (prévention Achille), vous perdez **la protection scientifique contre les deux blessures les plus fréquentes chez un expert préparant un marathon avec des séances tempo + VO2max**.
   - **Contradiction directe** entre l'adaptation demandée et la safety_notes.

3. **Réduction de volume trop sévère en W5-W12**
   - W5 : 50 km vs 63 km prévus = -21%.
   - W6-W10 : ~50-55 km vs 63-69 km = -18% à -21%.
   - W11 : 65 km vs 75 km = -13% (acceptable).
   - **Le Bloc 2 et début Bloc 3 subissent une compression de 15-20% en continu**, ce qui ralentit les adaptations aérobies et de seuil. La progression_logic prévoit « Aucun delta entre semaines consécutives ne dépasse 15% en dehors des semaines de cutback » → vos réductions de volume semaine-à-semaine restent dans cette enveloppe, mais la **moyenne du bloc se contracte** (Bloc 2 = 55 km/sem en votre plan au lieu de 65 km/sem), impactant le volume d'adaptation cumulé.

4. **Absence de séance d'activation running court (shakeout) en W5-W12**
   - Le plan ne prévoit pas de "shakeout" facile en milieu de semaine avant le long run. Votre structure 2 séances force l'alternance tempo/VO2max avec rien entre la séance qualité et le long run (3-4 jours de silence running).
   - Safety_notes stipule : « 1 jour de repos ou mobilité entre les séances running (pattern : J1 run / J2 force ou mobilité / J3 tempo / J4 repos / J5 intervalles / J6 repos / J7 long run) ».
   - Votre W5 adapté : J1 facile + J3 tempo + J7 long run, avec J4-J6 libres = vous pouvez insérer une mobilité J2 et J6, mais c'est imposé par la contrainte, non prévu par le template.

5. **Cutback weeks (W4, W8, W12) viables mais sans marges de manœuvre**
   - W4, W8, W12 deviennent des "cutbacks purs" car le volume chute drastiquement (du jour où on supprime J2 force + J5 intervalles).
   - W4 → 33 km (vs 56 km cutback prévus = cohérent avec l'intention cutback).
   - W8 → 40 km (vs 56 km cutback prévus = acceptable, mais juste).
   - W12 → 40 km (vs 60 km cutback prévus = réduction plus agressive).
   - Les cutbacks deviennent des **"mini-cutbacks forcés"** chaque 4 semaines, ce qui pourrait induire une fatigue chronique relative si les semaines de charge (W5-W7, W9-W11) sont elles-mêmes réduites.

## Contradictions

1. **Safety_notes vs suppression du renforcement (CRITIQUE)**
   - Safety : « Nordic curls (ischio-jambiers) : dès W1, progression de 5-6 reps à 8 reps sur 4 séries. Prévention tendinite ischio-jambière proximale, risque n°1 du coureur de marathon pratiquant des intervalles à haute vitesse. »
   - Votre adaptation : Nordic curls supprimés (J2 force = intégralement retiré).
   - **Contradiction irrésoluble** : vous faites tempo + VO2max (~40 min/semaine d'intervalles en cumul W5-W12) SANS la protection Nordic curl. Statistiquement, risque blessure ischios ↑ significativement.
   - **Mitigation possible** : intégrer 3-4 Nordic curls minimal (3 séries, 5 reps) 2x/semaine dans des sessions mobilité rapides (5-8 min) les jours sans séance running. Mais cela échappe au template original (la force était prévue en J2 structuré).

2. **Progression_logic (Principe 3) vs alternance tempo/VO2max**
   - Texte : « SÉANCES TEMPO ET VO2MAX TOUTES LES SEMAINES SANS EXCEPTION ».
   - Votre plan : Tempo semaines impaires, VO2max semaines paires (en W5-W12).
   - **Contradiction** : le template interdit littéralement l'alternance. Mais pragmatiquement, alterner tempo (le mardi) une semaine et VO2max (le jeudi) la suivante est une adaptation connue en coaching (Renato Canova, larthan, etc.) — elle est fonctionnelle mais **non-conforme au template**.

3. **Volume cumulé W5-W12 vs Progression en 4 blocs**
   - Progression_logic : « Bloc 2 (W5-W8) : Volume de 63 à 68 km ».
   - Votre W5-W8 : ~50 km/sem.
   - **Vous ne dépassez jamais 55 km/sem en W5-W12**, alors que le Bloc 3 (W9-W12) prévoit 64-75 km.
   - Conséquence : l'adaptation physiologique aux long runs marathon (18-35 km) se fait sur **moins de volume total**, affaiblissant potentiellement les adaptations mitochondriales et glycogène du Bloc 3.

4. **Safety_notes : "Signes de surcharge" (3+ signes → cutback)**
   - Si les semaines de non-cutback (W5-W7, W9-W11) sont elles-mêmes à 50-55 km (proche du volume de cutback), la répétition de micro-cutbacks peut **déprimer les adaptations** au lieu de les consolider.
   - Exemple : W5 50 km, W6 50 km, W7 55 km, W8 40 km, W9 50 km, W10 55 km → la moyenne reste basse, le stimulus d'adaptation est atténué.

5. **Affûtage W13-W15 : tolérance relative**
   - W13-W15 : 48, 32, 20 km. Cette progression est **compatible** avec le tapering prévu (réduction progressive, maintien intensité).
   - **Moins de contradiction** ici : l'affûtage tolère mieux une réduction de fréquence car le volume est déjà minimal et l'intensité doit être préservée (ce que votre plan fait : tempo/run AM conservés).
