# Adaptability : musculation-intermediaire-upperlower-12sem + p1-reduce-frequency

## Rigidity score
**3/10**

## Patch approach
Le template est structurellement **rigide** sur la fréquence. Il est conçu pour 4 séances/semaine avec une logique de split haut/bas binaire (Upper A + Lower A le lundi/mardi, Upper B + Pull B le jeudi/vendredi). Réduire à 2 séances/semaine impose de fusionner les patterns, ce qui casse l'alternance Upper/Lower prévue et force une restructuration majeure de chaque semaine. Le contenu (charges, RPE, progressions) peut se préserver partiellement, mais le **timing de récupération** (repos 48h entre composés) et la **séquence intra-séance** (ne pas épuiser les stabilisateurs avant les composés) se heurtent à la contrainte.

## Concrete modifications

### Stratégie de fusion
Chaque semaine = **2 séances longues** (~100-110 min) :
- **Séance 1** : Lower A (squat) + Upper B (pull) — 3-4 jours de repos avant Séance 2
- **Séance 2** : Upper A (push) + Lower B (hinge) — 3-4 jours de repos avant Séance 1 suivante

Cet ordre limite la fatigue des stabilisateurs (core travaille toujours en fin).

### W1
- **S1 (jour 1)** : Lower A (Back Squat 4×8 RPE 6-7, Leg Press 3×10-12, Leg Ext, Leg Curl, Calf debout) + Upper B (Pull-up 4×6-8 RPE 6-7, Chest-Supported Row 4×10, Incline BP 3×10, Face Pull, Triceps Pushdown, Planche latérale). **Durée : 110 min.**
  - **Modification clé** : Enlever Lat Pulldown W3 pour respecter la durée. Pull-up suffit pour le pull vertical.
  - Core fin séance : planche latérale seulement (pas de dead bug → inutile post-séance longue).

- **S2 (jour 4-5)** : Upper A (Bench Press 4×8 RPE 6-7, OHP 3×8, Bent-over Row 4×8, Cable Fly 3×12-15, Curl biceps, Planche ventrale) + Lower B (Deadlift 4×6 RPE 6-7, RDL 3×10, Bulgarian Split Squat 3×8/jambe, Glute Bridge, Calf assis, Bird-dog). **Durée : 115 min.**
  - **Modification clé** : Supprimer Dips lestés W1 (trop d'isolation push + composés). Deadlift requis = pattern hinge.

### W2
- **S1** : Lower A + Upper B.
  - Lower A : Back Squat +5 kg, 4×8 RPE 7 ; Leg Press 4×10-12 (+1 série) ; autres isolations maintenues.
  - Upper B : Pull-up RPE 7 (progression reps ou leste) ; Chest-Supported Row +2 kg/haltère ; Incline BP +2 kg ; Face Pull et Triceps Pushdown stables.
  - **Durée : 110 min.**

- **S2** : Upper A + Lower B.
  - Upper A : Bench Press +2,5 kg RPE 7, 4×8 ; OHP +2,5 kg ; Bent-over Row +5 kg.
  - Lower B : Deadlift +5 kg RPE 7 ; RDL +2 kg/haltère ; Bulgarian Split Squat +2 kg.
  - **Durée : 115 min.**

### W3 (pic accumulation)
- **S1** : Lower A + Upper B.
  - Lower A : Back Squat tempo 3-1-1, 4×8 RPE 7-8 (charge légèrement réduite vs W2 pour maintenir tempo) ; Leg Press 4×12 ; Leg Curl 3×12-15 ; Calf debout 4×15-20.
  - Upper B : Pull-up tempo 3-0-1, 4×6-8 RPE 7-8 ; Chest-Supported Row 4×10-12 ; Incline BP 3×10-12 ; Lat Pulldown remplacé par volume additionnel Face Pull (15-20 reps, santé épaule).
  - **Durée : 115 min.**

- **S2** : Upper A + Lower B.
  - Upper A : Bench Press tempo 3-0-1 (légère réduction charge vs W2), 4×8 RPE 7-8 ; OHP 4×8-10 ; Bent-over Row 4×8-10 ; Dips machine 3×8-10 (nouveau W3, moins lourd que dips barre) ; Cable Fly 3×15 ; Curl biceps 3×12-15.
  - Lower B : Deadlift 4×6 RPE 7-8 ; RDL 4×10 (+1 série) ; Bulgarian Split Squat 3×10/jambe ; Nordic Curl 3×5-6 (nouveau W3, introduction).
  - **Durée : 120 min.**

### W4 (cutback)
- **S1** : Lower A allégée.
  - Back Squat charge W2, 3×8 RPE 6 ; Leg Press 3×10 ; Leg Curl 2×12 ; Calf 3×15 ; Planche ventrale 3×30 sec.
  - **Durée : 70 min.**

- **S2** : Upper A allégée.
  - Bench Press charge W2, 3×8 RPE 6 ; OHP 3×8 ; Bent-over Row 3×8 ; Cable Fly 2×15 ; Curl 2×12 ; Planche latérale 2×25 sec.
  - **Durée : 65 min.**

**Attention W4** : Deadlift et Pull-up (composés majeurs) n'apparaissent PAS en W4 cutback. C'est une **rupture logique du plan**. Le plan prévoit que W4 est "consolidation" (même charge W2, -1 série), mais ici on a manqué des composés majeurs sur 2 semaines (W1-W3 sans deadlift les semaines où pull-up absent). Solution : ajouter **mini-séance de décharge W4** (jour 3, 30 min) : Deadlift 2×4 RPE 5, Pull-up 2×5 RPE 5 seulement pour maintenir le pattern.

### W5-W8 (Bloc intensification)
Même logique : S1 = Lower A + Upper B, S2 = Upper A + Lower B.

**W5 S1** :

**W5 S2** :

**W6-W7** : Intégrer top sets et back-off sets selon le template, maintenir les 2 séances longues.

**W8 (cutback bloc 2)** : Réduire volume -15%, 2 séances courtes (~70 min chacune).

## Rigidity issues

- **Composés mineurs disparaissent certaines semaines** : W1-W3, le deadlift n'apparaît qu'une fois par cycle (S2). Idéalement deadlift doit être hebdomadaire (sécurité pattern + progression). Même problème pull-up vs Lat Pulldown — l'alternance haut/bas casse.

- **Cutback W4 et W8 cassent le pattern** : Le plan crée une "mini-séance" de 30 min juste pour maintenir les composés majeurs omis. Peu élégant.

- **Durée séances intra-semaine** : Le template prévoit 60-75 min par séance. Fusionner Upper+Lower = 110-120 min si on préserve tout. Impossible de tenir en 75 min → **suppression d'isolations ou réduction reps sur isolations obligatoire**.

- **Repos composés lourds** : Le plan exige 3 min repos sur composés (ACSM/NSCA, safety_notes W1). Bench + Deadlift le même jour (S2) = 6 min d'attente passif minimum entre les composés = séance très longue. Acceptable mais à documenter.

- **Progression linéaire** : Ajouter 2,5-5 kg chaque semaine sur 4 composés devient agressif sur 2 séances (moins de récupération globale). Le risque de stagnation ou surentraînement augmente.

## Contradictions

- **Safety_notes W1** : "Repos entre composés lourds MINIMUM 2 minutes, recommandé 3 minutes". Avec 2 séances/semaine combinant 4 composés majeurs (Bench, OHP, Row, Squat, Deadlift), le repos intra-séance dépasse facilement les recommandations, rallongeant la séance bien au-delà de 100 min. La recommandation ACSM/NSCA suppose une séance avec 3-4 composés maximum, pas 4-5.

- **Progression_logic W1** : "DOUBLE PROGRESSION SUR LES COMPOSÉS". Le template prévoit une montée progressive et mesurée (6 → 8 reps → charge +2,5 kg). Avec 2 séances/semaine et volume réduit par séance (moins d'isolations), la **supercompensation est plus lente** — risque de RPE réel > RPE ciblé (fatigue cumulée non perçue) → faux positif de progression.

- **Periodization W5-W8** : "SÉRIES TOP SET ET AMRAP". Top set suppose une montée de charge progressive et une prise de risque maximale (RPE 9-10). En 2 séances/semaine, le système nerveux est déjà sollicité sur 2-3 composés majeurs par séance. Ajouter un top set chaque semaine augmente le risque de surentraînement neuromusculaire sans augmenter la récupération.

- **CUTBACKS OBLIGATOIRES W4 ET W8** : "Ces semaines sont constitutives de la performance finale, pas des semaines perdues." Avec 2 séances/semaine, un cutback identique (-15% volume) est **moins effectif** car le volume total est déjà réduit. W4 cutback = réduction extrême, risque de désentraînement temporaire.

- **Nordic Curl (safety W5)** : Introduit en W3, censé être hebdomadaire (W3-W12, progression 5 → 8 reps). Avec la fusion Squat+Pull une semaine et Push+Hinge la suivante, Nordic Curl tombe tantôt en fin de séance courte (fatigue accumulée peu probable), tantôt en fin de séance de 120 min (fatigue maxima du système nerveux → risque accru tendinopathie). La **variabilité de contexte augmente le risque**.

- **DOMS et courbatures (safety W1)** : "DOMS attendu en début de bloc ou après introduction d'un nouveau mouvement." Avec 2 séances/semaine fusionnées (haut+bas le même jour), les courbatures s'additionnent (quadriceps + pectoraux + dorsaux simultanément). La distinction DOMS vs douleur articulaire devient plus compliquée à la perception. Risque de faux diagnostic (ignorer une tendinite ischio pour une "simple" courbature musculaire).
