Glossaire enrichi pour compenser :
  • drill (FR + EN) — définition générique avec exemple du drill rattrapé natation : « un bras tendu devant attend que l'autre bras fasse le cycle complet et vienne le toucher, puis ce dernier redémarre. Isole la glisse et la coordination. »
  • plank / planche / side plank — déjà ajouté Jalon 1
Récap des 10 patterns strength illustrés :
  • Squat — 3 frames : debout barre épaules → mi-squat → fond
  • Hinge (RDL) — 3 frames : debout haltères → 45° → 80° (hanche recule, dos droit)
  • Push horizontal (pompe / bench) — 3 frames vue profil : position haute → descente → poitrine près du sol
  • Push vertical (overhead press) — 3 frames : haltères épaules → mi-hauteur → bras tendus au-dessus tête
  • Pull horizontal (row / rameur) — 3 frames : corps penché fixe + barre qui se rapproche du tronc
  • Pull vertical (pull-up / chin-up) — 3 frames référentiel observateur : corps fixe pieds au sol + barre qui descend au menton
  • Lunge (fente avant) — 3 frames : pieds joints → fente arrière → fond fente
  • Plyo (jump squat) — 3 frames exception saut explicite : squat préparation → saut pieds décollés + chevrons → atterrissage genoux fléchis
  • Core — plank frontal (planche) — 1 frame statique + ligne d'alignement pointillée orange
  • Core — plank latéral (side plank) — 1 frame statique : 1 seul avant-bras au sol + bras libre tendu vers le haut
  • Mobility (étirement quadriceps) — 1 frame statique + arc pointillé orange suggérant l'étirement
