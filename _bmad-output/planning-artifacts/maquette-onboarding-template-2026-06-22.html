Les règles du template

  • Deux zones franches : ta demande (texte libre + tuiles) ↕ la restitution de Léon (fond bleuté, avatar). On ne confond plus qui parle.
  • Aperçu vivant : tu modifies ta demande → la proposition se recompose. Rien n'est figé avant le bouton vert (le seul moment ferme).
  • Multi-sport via la bulle conservé : « vélo + course » → Léon dit, dans sa zone, comment il gère.
  • Tuiles couleur = identité sport (vraies icônes SF Symbols + couleurs Color.coachingSport en app ; emojis = placeholder maquette). Sélectionné = tuile remplie.
  • Léon ✓ / ⏳ : ✓ il fait · ⏳ pas encore (loggé → backlog de demandes réelles). Vert = valider (transversal app). Zéro saisie corporelle.
