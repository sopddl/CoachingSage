Onglet « Séances » — 4 modes

Refonte SessionView vers un dashboard Séances (pas Aujourd'hui) — centre de gravité = prochaine séance, pas le calendrier. Inspiration : pattern Multi-day peek (TrainingPeaks) + rest day narratif (Runna) + routines persos (Hevy). Différenciateur CoachingSage : multi-program assumé (vs Nike Training Club qui force 1 prog à la fois).

Party 2026-05-07 · 5 décisions tranchées user-first · personas Sophie / Nathalie / Philippe / Maxime

4 modes du même squelette — la grammaire (cards, tab bar, "+"" en nav, hint italique Léon) reste identique.
  • ① Mode vide (Nathalie, 0 programme) — hero CTA + 2-3 templates suggérés depuis l'autoprofil HK + onboarding (raccourci) ; lien "sur mesure" en secondaire vers le questionnaire universel Phase 2 #5. Pas de routines en mode vide (décision party #4).
  • ② Mode actif multi-prog (Sophie, 3 programmes triathlon) — card prochaine séance dominante (couleur sport), liste programmes en cours compactes triées par date prochaine séance (décision party #3), 1-2 routines persos, "+" nav bar, CTA Réorganiser ma semaine.
  • ③ Mode actif 1-prog (Philippe, plan semi-marathon seul) — card prochaine séance + mini-widget "Cette semaine" (volume / séances / streak) + card "Et après" Today+Tomorrow style TrainingPeaks (décision party #2 — B+C combinés). Réutilise les composants existants.
  • ④ Mode rest day (1 programme actif, jour de récup) — card verte narrative "Récup", info "prochaine séance dans 2j", CTA "Réorganiser ma semaine" si l'envie.
Léon = FAB flottant bleu coach à cheval sur la tab bar (pattern FloreFloatingButton GardenSage : circle 54pt, ombre soft, offset y -32). Accessible depuis tous les écrans, pas un onglet — la chat sheet ouvre par-dessus tant que Story 3.6 pas livrée. Tab bar = 3 onglets seulement : Séances · Progrès · Profil.

Décisions tranchées 5/5 — user-first

Sophie 2026-05-07 : « je veux le mieux pour le user tant pis si plus de boulot ». Coût total révisé : ~10-12j d'impl (Story 3.8 Séances 6-7j + Story 3.9 Progrès 4-5j) vs 5j si on était resté sur recos initiales.

  • ① Onglet Progrès = A — Agrégé multi-sport complet (charts HK + volume par sport + PRs). Couvre les 4 personas qui demandent du visuel motivant. Story 3.9 dédiée, +3-5j vs hybride.
  • ② Mode actif 1 prog = B+C combinés — mini-widget "Cette semaine" + card "Et après" (Today+Tomorrow style TrainingPeaks). Composants existants, faible coût.
  • ③ Tri cards programmes = par date prochaine séance (actionnable > sentimental). Logique simple, le programme qui réclame attention aujourd'hui passe en haut.
  • ④ Routines en mode vide = jamais. Nathalie surchargée si on parle de routines en arrivée. Apparaissent dès 1ère séance complétée.
  • ⑤ Réorganiser ma semaine = drag & drop hebdo Phase 2. Complémentaire Léon (drag & drop = timing, Léon = contenu). Composant WeeklyCalendarView amorti sur 3 usages (Séances + zoom prog + calendrier global). +2-3j.

Décisions structurelles tranchées : nom = Séances (pas Aujourd'hui), tab bar 3 onglets + FAB Léon bleu coach #1E5090 (pattern FloreFloatingButton GardenSage), Léon chat absent tant que Phase 2 #6 (Story 3.6) pas livré, multi-program assumé comme différenciateur, progression triathlon = écran zoom séparé.
