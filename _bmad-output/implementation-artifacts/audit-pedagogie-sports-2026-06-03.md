## 1. Patterns transverses (gain maximal — à traiter une fois pour tous les sports)

**A. Le glossaire ne tourne PAS sur les titres, seulement sur `notes`** — *fix CODE, 1 ligne, impact 10/10 sports.*
`ExerciseTimelineCard.swift:84` rend `displayName` en `Text(verbatim:)` ; `Glossary.matches` ne s'applique qu'à `exercise.notes` (`:49-51`). Or le jargon (CSS, FTP-Z5, 30/30, MD-3, Daniels-T…) est dans le TITRE, lu en premier. **Faire passer `displayName` + nom de séance par `GlossaryRichText`** rend 80% du jargon tappable sans toucher un seul JSON. C'est le meilleur ratio effort/gain de tout l'audit.

**B. `target_zone` affiché brut = codes cryptiques** (7/10 sports). Les valeurs machine (`Z2`, `30/30`, `FTP-Z5`, `RPE 8-9 sprint`, `REC`, `SP1`) s'affichent telles quelles. Deux remèdes globaux : mapper zone→libellé lisible à l'affichage (`Z2`→« endurance, peux parler »), ET router le `GlossaryMatcher` sur le numéro de zone AVANT les fallbacks génériques (cf. bug vélo : `Z4/Z5/Z6/Z7` retombent tous sur la fiche « FTP »).

**C. Trous massifs dans le glossaire** (tous sports). ~120 termes affichés sans entrée : SP1/2/3, taper, EVF, DPS/SPL, dryland (natation) ; SFR, opener, ERG, sweet-spot (vélo) ; TM/Training Max, SNC, pattern/hinge (muscu) ; WOD, For Time, 30/30, all-out, Cindy/FRAN (HIIT) ; MD-3, RSA, AA, NHE/CAE (foot) ; ME, S&C, Z2-cardiac, fastpacking, cotation SAC (rando) ; mini-tennis, ghost-stroking, trophée (tennis). **Un seul chantier glossaire mutualisé** + matcher pour codes zones.

**D. Noms de séances = empilement jargon EN + chiffres** (running, vélo, natation, triathlon, muscu, HIIT, rando, tennis, foot — tous sauf yoga). Gabarit transverse à imposer : `<discipline en clair> <intention en mots> — <détail chiffré> (<code en parenthèses>)`. Ex : « Sortie endurance FTP-Z2 » → « Sortie endurance, allure conversation (Z2) ».

**E. « Comment l'exécuter » repose sur 12-22 seeds force only** (running, tennis, HIIT critiques). `ExerciseExplanationSeed.swift` ne couvre que la muscu ; le fetcher IA est un stub V1 qui échoue toujours → les gestes-cœur du sport (strides, service tennis, Turkish get-up, KB swing) retombent sur un tip générique par pattern. **Aucun ExercisePattern tennis (0 case), aucun seed running/swim/tennis.**

**F. Franglais + notes-référence vides sur occurrences répétées** : la consigne n'existe qu'à la 1re occurrence du mouvement → un user qui ouvre W5 voit « Pose #6. » / « Turkish get-up » nu. Fallback à coder : aller chercher la note la plus riche de la même posture/exo dans le template.

**G. Fuites de génération visibles à l'écran** : `(master prompt §2.6)` (natation), accents absents tout le fichier (foot competitive), « simulacre »/« proxy » (vélo). Purge texte.

**H. Hooks Schema v2 vides** (triathlon, foot, rando) : `week_structure: null`, `deload_weeks: None` alors que les deloads existent → Léon ne sait pas où alléger.
